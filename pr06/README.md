# PR-6. Синхронизация (Вариант C)

## Цель работы
Реализация низкоуровневого спинлока на базе атомарных инструкций __atomic_test_and_set и решение классической проблемы «Читатели–Писатели».

## Верификация кода
- Код проверен с помощью статического анализа и динамического инструмента ThreadSanitizer (-fsanitize=thread) для полного исключения гонок данных (data races).
