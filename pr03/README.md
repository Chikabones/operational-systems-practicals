# PR-3. Процессы в Linux (Вариант C)

## Цель работы
Разработка полноценной командной оболочки (Mini-shell) на языке C с поддержкой порождения процессов, каналов (pipe), перенаправления потоков (dup2) и обработки сигналов.

## Ключевые особенности реализации
- Поддерживает системные вызовы ork, execvp, waitpid.
- Реализованы встроенные команды cd и exit.
- Корректно обрабатывает перенаправление ввода/вывода без оставления процессов-зомби.
