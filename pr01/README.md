# PR-1. Диагностическое тестирование и системные службы (Вариант C)

## Цель работы
Развертывание минимальной Ubuntu Server / Alpine, настройка безопасного SSH-доступа, создание кастомного systemd unit-файла и анализ времени инициализации ОС.

## Реализация и шаги выполнения
1. **Безопасный SSH-доступ**: Выделен ключ ssh-rsa, отключена авторизация по паролю в /etc/ssh/sshd_config.
2. **Системные службы (Systemd vs OpenRC)**: Оформлена сравнительная таблица синтаксиса команд (systemctl против c-service).
3. **Unit-файл Systemd**: Написан скрипт 	ime_writer.py, создана служба /etc/systemd/system/timewriter.service с автозапуском (systemctl enable --now).
4. **Анализ загрузки**: Выполнена диагностика через systemd-analyze blame.
