# PR-2. Bash и системные вызовы (Вариант C)

## Цель работы
Исследование накладных расходов перехода «пользователь — ядро» при помощи замера времени копирования файла 100 МБ с различным размером буфера (1, 64, 4096, 65536 байт).

## Анализ результатов
- При размере буфера в 1 байт происходит колоссальное падение производительности из-за миллионов системных вызовов ead/write и частых переключений контекста.
- Использование стандартных буферов (4 КБ и выше) оптимизирует работу подсистемы ввода-вывода.
- Прямой вызов syscall(SYS_write, ...) подтверждает идентичность результатов со стандартной оберткой libc.
