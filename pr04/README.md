# PR-4. Потоки в C (Вариант C)

## Цель работы
Параллельное суммирование массива из ^8$ элементов с использованием библиотеки pthreads, измерение ускорения (speedup) и исследование явления **False Sharing** (ложное разделение кэш-линий).

## Результаты анализа
- Прирост производительности наблюдается вплоть до достижения количества физических ядер процессора.
- Размещение счетчиков потоков вплотную друг к другу приводит к частому сбросу кэш-линий процессора (64 байта), что преодолевается выравниванием памяти (padding).
