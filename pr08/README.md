# PR-8. Взаимоблокировки и Deadlocks (Вариант C)

## Цель работы
Реализация задачи об обедающих философах с предотвращением тупиковых ситуаций (deadlocks) через упорядочивание ресурсов.

## Результаты
- Применение стратегии асимметричного захвата вилок полностью исключает циклическое ожидание (Circular Wait), предотвращая зависание системы.
