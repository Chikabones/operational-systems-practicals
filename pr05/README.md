# PR-5. Симулятор планирования CPU (Вариант C)

## Цель работы
Реализация многоуровневой очереди с обратной связью (MLFQ) с тремя уровнями приоритетов и динамическим изменением квантов времени.

## Особенности алгоритма
- Задачи, исчерпавшие свой квант, опускаются на уровень ниже.
- Интерактивные задачи (завершающие работу раньше кванта) сохраняют высокий приоритет.
- Предусмотрен периодический механизм boost для предотвращения голодания.
