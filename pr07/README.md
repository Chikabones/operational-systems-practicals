# PR-7. Межпроцессное взаимодействие (Вариант C)

## Цель работы
Сравнительный бенчмаркинг четырех механизмов IPC ( Pipes, POSIX MQ, Shared Memory, Unix Sockets) при передаче блока данных размером 1 ГБ.

## Выводы
- Разделяемая память является самым быстрым механизмом, так как исключает накладные расходы на копирование данных между пользовательским пространством и ядром.
